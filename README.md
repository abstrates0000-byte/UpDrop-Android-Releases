# UpDrop Android Releases

Repositorio público **solo para APKs firmadas** de UpDrop Android. El código fuente permanece en un repositorio privado.

Las versiones oficiales se publicarán en [GitHub Releases](../../releases) como `UpDrop-Android.apk`, con versión `vA.B.C` y digest SHA-256 proporcionado por GitHub. La app compara huella, paquete y certificado de firma antes de abrir el instalador de Android.

**Aún no hay una versión pública verificada.** No instalar APKs de fuentes no oficiales.
